# Week 4 Internship Task Submission Description: Machine Learning Model Development and Evaluation

## Project Title:
End-to-End Machine Learning Model Development for Customer Churn Prediction: A Comparative Evaluation of Parametric, Non-Linear Tree, and Ensemble Architectures in Python

## Detailed Report Description (For Submission Portal):

This technical report presents a comprehensive, production-grade machine learning engineering project developed in Python using Scikit-Learn to address the challenge of subscriber retention and customer churn prediction. Operating on a curated enterprise dataset of N = 3,500 customer accounts characterized by 14 demographic, contract, and behavioral features, the study implements an end-to-end predictive pipeline encompassing exploratory data analysis, leakage-free preprocessing, multi-model training, 5-fold stratified cross-validation, comprehensive metric benchmarking, and empirical diagnosis of the bias-variance trade-off.

The data preprocessing architecture was engineered using Scikit-Learn's `ColumnTransformer` and `Pipeline` objects. To prevent data leakage, continuous numerical features (tenure, monthly billing, cumulative charges, customer support calls) were standardized via `StandardScaler` fitted strictly on the 80% training partition (N_train = 2,800), while nominal categorical variables (contract type, internet service, payment method, support add-ons) were transformed using `OneHotEncoder(drop='first')` to prevent multicollinearity. An 80/20 stratified split preserved the 15.6% minority churn incidence across both partitions.

Three distinct algorithmic paradigms were benchmarked:
1. Baseline Model — Logistic Regression (with L2 Ridge Regularization): Delivered the highest overall discriminative performance and probability calibration on the holdout test set (ROC-AUC = 0.864, PR-AUC = 0.546, Accuracy = 86.57%, Balanced Accuracy = 63.99%, F1-Score = 0.420, Brier Score = 0.096), while providing transparent odds-ratio interpretability.
2. Non-Linear Rule Induction — Decision Tree Classifier: Evaluated under both unconstrained and cost-complexity pre-pruned regimes (max_depth = 5, min_samples_leaf = 10). Pruning successfully mitigated catastrophic overfitting (restoring test Accuracy to 84.14% and ROC-AUC to 0.796), establishing inspectable if-then decision thresholds.
3. Ensemble Architecture — Random Forest Classifier (150 de-correlated estimators): Achieved superior classification specificity (97.97%) and robust ensemble generalization (Accuracy = 85.86%, ROC-AUC = 0.845, PR-AUC = 0.514), identifying account tenure, cumulative spend, and month-to-month contracts as the primary predictive drivers of customer defection via Gini impurity decrease.

A critical evaluation of error distributions highlighted the stark financial cost asymmetry between False Positives (low-cost retention offers) and False Negatives (lost customer lifetime value exceeding $800). Consequently, decision threshold tuning (adjusting from 0.50 to 0.28) was demonstrated to more than double retention recall (from 31% to >65%). Empirical learning curves further substantiated the bias-variance trade-off across varying training sizes.
