# Week 3 Internship Task Submission Description: Statistical Analysis and Hypothesis Testing in Python

## Project Title:
Empirical Evaluation of Digital Product Interventions: A Multi-Factor Hypothesis Testing & Inferential Statistical Analysis on E-Commerce User Engagement and Revenue

## Detailed Report Description (For Submission Portal):

This technical report presents a comprehensive, production-grade inferential statistical analysis and hypothesis testing study conducted in Python to evaluate the commercial, behavioral, and engagement impacts of digital product interventions on a large-scale e-commerce platform. Operating on a curated experimental dataset comprising N = 3,000 unique user sessions, the project investigates four distinct, mathematically formulated research hypotheses spanning continuous revenue metrics, categorical conversion dynamics, multi-channel acquisition patterns, and longitudinal within-subject customer retention.

The analytical pipeline was built using Python's foundational scientific computing stack—primarily SciPy Stats (`scipy.stats`), Statsmodels (`statsmodels.api`, `statsmodels.stats.multicomp`), Pandas, and NumPy—alongside Seaborn and Matplotlib for publication-quality visual diagnostics. To ensure academic rigor and avoid Type I error inflation, every inferential test was preceded by empirical assumption testing. This included Shapiro-Wilk and D'Agostino-Pearson omnibus tests for normality, Levene's median-centered tests for homoscedasticity, and quantile-quantile (Q-Q) distributional inspections. Furthermore, parametric results were systematically benchmarked against non-parametric alternatives (Mann-Whitney U and Wilcoxon Signed-Rank tests), and standardized effect sizes (Cohen's d, Cramér's V, and Eta-squared η²) were computed to gauge practical, real-world relevance.

Key empirical findings include:
1. Revenue & Average Order Value (AOV): A two-sample Welch's t-test demonstrated that the Treatment group's machine-learning recommendation flow generated a statistically significant AOV uplift of +$6.55 per converted order (t(472.4) = 3.324, p = 9.56e-04, 95% CI: [+$2.68, +$10.42], Cohen's d = 0.298), verified by a Mann-Whitney U test (p = 2.40e-03).
2. Device Conversion Independence: A Pearson Chi-Square Test of Independence on a 3x2 contingency table decisively rejected device independence (χ²(2) = 20.985, p = 2.77e-05, Cramér's V = 0.084). Standardized Pearson residual analysis revealed severe mobile checkout friction (13.68% conversion, residual = -2.79) compared to desktop dominance (20.06% conversion, residual = +2.87).
3. Multi-Channel Engagement Heterogeneity: A One-Way ANOVA across four traffic acquisition sources revealed significant engagement variance in session duration (F(3, 2996) = 402.37, p < 1e-100, η² = 0.287). Tukey's Honestly Significant Difference (HSD) post-hoc test confirmed that Email Campaign visitors engaged longest (mean = 6.71 mins), followed by Organic Search (5.54 mins), Paid Search (3.89 mins), and Social Media (2.80 mins), with all pairwise contrasts rejecting equality (adjusted p < 0.001).
4. Customer Loyalty & Retention: A paired samples t-test on a repeat customer cohort (N = 526) established a significant within-subject satisfaction gain of +1.34 points on a 10-point scale following personalized onboarding (t(525) = 35.16, p = 4.26e-140, Cohen's dz = 1.53, Wilcoxon p = 2.15e-77).

The complete deliverable package includes a formatted, publication-style Word document (`Week3_Statistical_Analysis_Report.docx`) with embedded high-resolution figures, structured diagnostic tables, annotated Python code snippets, actionable business recommendations, risk management trade-offs (Type I vs Type II errors), and full GitHub repository documentation.
