# Week 2 – Advanced COVID-19 Data Visualization and Storytelling

## Overview
This project analyzes COVID-19 public-health data using Python and creates visualizations to identify important patterns in cases, deaths, vaccination, mortality, and healthcare pressure.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- NumPy

## Visualizations
1. Global COVID-19 Cases and Deaths
2. COVID-19 Waves Across Five Major Countries
3. Vaccination Progress (2021–2023)
4. Country Vaccination Comparison
5. COVID-19 Deaths by Age Group
6. Reported COVID-19 Deaths per 100,000 Population
7. Reported New COVID-19 Hospitalizations

## Files
- `Week2_Advanced_COVID_Data_Storytelling_Report_FINAL.docx` – Project report
- `Week2_Advanced_COVID_Data_Storytelling.py` – Python code
- CSV files – Datasets used for analysis

## Objective
The main objective is to use data visualization and storytelling techniques to understand COVID-19 trends and communicate meaningful public-health insights.
